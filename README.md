# OmniChat - Omni-Channel Communication Platform

A modern, ChatGPT-inspired interface for business communication, built with Next.js and Tailwind CSS. OmniChat helps with employee management, recruitment, accounting, and e-invoicing.
https://omni-chat-fawn.vercel.app/
## Features

- 🎨 Modern ChatGPT-like interface
- 🔐 Secure login page
- 💬 Real-time chat interface
- 📱 Responsive design
- 🎯 Specialized in:
  - Employee Management
  - Recruitment
  - Accounting
  - E-Invoicing

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **React Hooks** - State management
